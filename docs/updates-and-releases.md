# Updates & Releases

This page tracks significant feature releases and updates to gftv.asia. The most recent changes are listed first.

---

## Link Ownership Requests

**Released:** 2025

Officers can now formally request ownership of a link they don't own, directly through the platform. The current owner receives the request and can approve or reject it with a single click. This replaces the previous need to coordinate transfers out-of-band.

See [Ownership Requests](managing-links/ownership-requests.md) for details.

---

## Two-Factor Authentication (2FA)

**Released:** 2025

All gftv.asia accounts can now enable TOTP-based two-factor authentication. Supported by any standards-compliant authenticator app (Google Authenticator, Authy, 1Password, etc.). Includes:

- QR code and manual setup key entry.
- Backup codes for account recovery.
- Trusted device support — skip 2FA on known devices for 30 days.
- Per-device session management.

See [Two-Factor Authentication](your-account/two-factor-authentication.md) and [Trusted Devices](your-account/trusted-devices.md).

---

## Link Tags

**Released:** 2025

Short links can now be labelled with up to **5 tags** each. Tags make it easy to organise links by campaign, event, or topic and let other officers find related links via tag-based search in the Directory.

See [Link Tags](managing-links/link-tags.md).

---

## QR Code Generation

**Released:** 2025

Any short link can now generate a downloadable **composite QR code image** — a PNG containing the QR code and the printed short link URL. The image can be downloaded, copied to clipboard, or shared natively on mobile.

See [QR Codes](managing-links/qr-codes.md).

---

## Pre-Approval System

**Released:** 2025

Admins can now pre-approve email addresses before new officers register. Pre-approved users are instantly activated with the correct role when they sign up — no manual approval step required.

See [Pre-Approval System](for-admins/pre-approval-system.md).

---

## User Profiles & Social Links

**Released:** 2025

Every officer now has a public profile page showing their role badge, avatar, link statistics, and any social links they choose to share. Profile views are tracked and shown to the profile owner as a "recent viewers" list.

See [User Profiles](directory/user-profiles.md) and [Profile & Settings](your-account/profile-and-settings.md).

---

## Link Analytics

**Released:** 2025

Each short link now tracks a cumulative **view count** — the total number of redirect events since the link was created. View counts are visible on the Dashboard, in the Directory, and on user profiles (as an aggregate).

See [Link Analytics](managing-links/link-analytics.md).

---

## Platform Launch

**Released:** 2025

gftv.asia launched as the official link shortener for GFTV (Global Furry Television). Core features at launch included:

- Short link creation with custom slugs for verified GFTV officers.
- Public Directory for browsing all platform links.
- Admin panel for user and link management.
- Edge-runtime redirect handler for ultra-low latency redirects.
- 7 colour themes via the theme selector.
- PWA (Progressive Web App) support — installable on mobile and desktop.
