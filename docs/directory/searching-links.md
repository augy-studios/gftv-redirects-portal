# Searching Links

The [Directory](browsing-the-directory.md) includes a search function that helps you find specific links quickly. There are three search modes, each suited to a different use case.

## Switching search modes

At the top of the Directory, look for the search bar with a mode selector. Click the mode label (or a dropdown/toggle) to switch between:

- **Keyword**
- **Tag**
- **Username**

## Keyword search

**Keyword** mode searches across both the **slug** and the **destination URL** of all links.

Use this when:
- You know part of the short link slug (e.g. searching `disc` to find `gftv.asia/discord`).
- You know part of the destination URL (e.g. searching `youtube.com` to find all links pointing to YouTube).
- You want to explore links in a broad topic area.

**Example:** Typing `telegram` would return links like `gftv.asia/telegram` or any link whose destination URL contains the word "telegram".

## Tag search

**Tag** mode finds all links that have been labelled with a specific tag.

Use this when:
- You want to find all links related to a particular event or campaign.
- You know the tag name used by a team to categorise their links.

**Example:** Typing `events-2025` would return all links tagged with `events-2025`.

{% hint style="info" %}
Tag search is exact-match (not partial). Searching `event` will not return links tagged `events-2025`. Enter the full tag name for best results.
{% endhint %}

## Username search

**Username** mode finds all links created by a specific GFTV officer.

Use this when:
- You want to see all links managed by a particular team member.
- You are looking for a link you know was created by a specific person.

**Example:** Typing `augy` would return all links owned by the user with the username `augy`.

{% hint style="info" %}
Username search is also accessible by visiting a user's [profile page](user-profiles.md) directly, which lists all their links automatically.
{% endhint %}

## Clearing a search

To return to the full Directory listing, clear the search input or click the **×** button in the search bar.

## Frequently asked questions

**Can I combine multiple search modes at once?**
No. Only one search mode is active at a time. Switch modes using the selector.

**Is search case-sensitive?**
No. Searches are case-insensitive — searching `Discord` and `discord` will return the same results.

**Does search return inactive links?**
Yes. Both active and inactive links appear in search results. Inactive links are labelled with a grey badge.
