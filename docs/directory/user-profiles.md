# User Profiles

Every GFTV officer on gftv.asia has a public profile page. Profiles help the community understand who is behind a link and provide a central place to see all the links an officer manages.

## Viewing a profile

You can reach a user's profile in two ways:

1. **From the Directory** — Click the creator's name or avatar on any link card.
2. **Direct URL** — Navigate to `gftv.asia` and look up the user by username.

No login is required to view profiles.

## What a profile shows

| Section | Details |
|---|---|
| **Avatar** | The user's profile picture |
| **Display name** | The name the user has set (may differ from their username) |
| **Username** | The user's unique handle |
| **Role badge** | Shows whether the user is an **Admin**, **Editor**, or **Viewer** |
| **Statistics** | Total links created and total combined view count across all their links |
| **Social links** | Any external links the user has added (e.g. Twitter, LinkedIn, personal site) |
| **Links list** | All short links owned by this user |
| **Recent viewers** | A list of logged-in users who have recently visited this profile |

## Role badges

Role badges appear on a user's profile to indicate their standing on the platform:

| Badge | Meaning |
|---|---|
| **Admin** | This officer has full administrative access to the platform |
| **Editor** | This officer can create and manage short links |
| **Viewer** | This officer has read-only access |

## Recent viewers

When a logged-in user visits a profile, the visit is recorded and the profile owner can see a short list of **recent viewers** on their own profile page. This is similar to a "who viewed your profile" feature.

{% hint style="info" %}
Profile views are only recorded for **logged-in** users. Anonymous (not logged in) visitors do not appear in the recent viewers list.
{% endhint %}

## Your own profile

Your own public profile is what other users and community members will see when they look you up. To update what appears on your profile, see [Profile & Settings](../your-account/profile-and-settings.md).

## Frequently asked questions

**Can I hide my profile from the public?**
No. Profiles for active accounts are publicly visible. If you are concerned about privacy, keep your display name and social links minimal.

**Can I see a profile for a deleted account?**
No. When an account is deleted, its profile page is no longer accessible.

**What if a user's links show as inactive on their profile?**
The profile still lists the links but they will show the grey **Inactive** badge. Clicking an inactive link will redirect to the GFTV blog rather than the original destination.
