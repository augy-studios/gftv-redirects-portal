# Browsing the Directory

The **Directory** is a public listing of all active and inactive short links on gftv.asia. Anyone with an account with Viewer access can browse it.

## Accessing the Directory

Go to [gftv.asia](https://gftv.asia), log in to your account, and click **Directory** in the navigation bar.

## What you'll see

The Directory displays **link cards**, one for each short link on the platform. Each card shows:

| Field               | Description                                                                    |
| ------------------- | ------------------------------------------------------------------------------ |
| **Slug**            | The short link path (e.g. `gftv.asia/discord`) with a copy-to-clipboard button |
| **Destination URL** | Where the link points                                                          |
| **Creator**         | The username and avatar of the GFTV officer who created the link               |
| **Status badge**    | Green **Active** or red **Inactive**                                           |
| **View count**      | Total number of times the link has been visited                                |
| **Tags**            | Any tags the creator has applied to the link                                   |

## Navigating link creator profiles

Clicking on a link creator's name or avatar takes you to their public [user profile](user-profiles.md), where you can see all the links they've created and any social links they've shared.

## Status badges

| Badge        | Meaning                                                                                      |
| ------------ | -------------------------------------------------------------------------------------------- |
| **Active**   | The link is live. Clicking it will redirect to the destination.                              |
| **Inactive** | The link has been disabled by its owner. Clicking it will redirect to the GFTV blog instead. |

## Filtering and searching

Four controls at the top of the Directory let you narrow down and reorder results:

* **Keyword search** — searches the slug, destination URL, display name, and username simultaneously.
* **Tag filter** — narrows results to links carrying a specific tag.
* **Status filter** — show All, Active, or Inactive links.
* **Sort order** — sort by Date Created (newest first) or Most Visits.

All filtering and sorting happen client-side, so the controls respond instantly without reloading the page.

See [Searching Links](searching-links.md) for a detailed walkthrough of each control.

## Frequently asked questions

**Do I need to log in to browse the Directory?** Yes. You will need to have Viewer access.

**Are inactive links shown in the Directory?** Yes. Inactive links are shown but clearly marked with a grey badge. They can still be found by search.

**How often is the Directory updated?** The Directory reflects the current state of all links in real time. New links appear immediately after they are created.
