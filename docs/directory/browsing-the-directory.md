# Browsing the Directory

The **Directory** is a public listing of all active and inactive short links on gftv.asia. Anyone can browse it — no account required.

## Accessing the Directory

Go to [gftv.asia](https://gftv.asia) and click **Directory** in the navigation bar.

## What you'll see

The Directory displays **link cards**, one for each short link on the platform. Each card shows:

| Field | Description |
|---|---|
| **Slug** | The short link path (e.g. `gftv.asia/discord`) with a copy-to-clipboard button |
| **Destination URL** | Where the link points |
| **Creator** | The username and avatar of the GFTV officer who created the link |
| **Status badge** | Green **Active** or grey **Inactive** |
| **View count** | Total number of times the link has been visited |
| **Tags** | Any tags the creator has applied to the link |

## Navigating link creator profiles

Clicking on a link creator's name or avatar takes you to their public [user profile](user-profiles.md), where you can see all the links they've created and any social links they've shared.

## Status badges

| Badge | Meaning |
|---|---|
| **Active** | The link is live. Clicking it will redirect to the destination. |
| **Inactive** | The link has been disabled by its owner. Clicking it will redirect to the GFTV blog instead. |

## Filtering and searching

Use the search bar at the top of the Directory to narrow down results. You can switch between three search modes:

- **Keyword** — searches both the slug and destination URL.
- **Tag** — finds links with a specific tag.
- **Username** — finds all links created by a specific officer.

See [Searching Links](searching-links.md) for a detailed walkthrough of each search mode.

## Frequently asked questions

**Do I need to log in to browse the Directory?**
No. The Directory is fully public.

**Are inactive links shown in the Directory?**
Yes. Inactive links are shown but clearly marked with a grey badge. They can still be found by search.

**How often is the Directory updated?**
The Directory reflects the current state of all links in real time. New links appear immediately after they are created.
