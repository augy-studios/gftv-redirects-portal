# Editing a Link

You can edit any link you own at any time from your Dashboard. Admins can edit any link on the platform regardless of ownership.

## How to edit a link

1. Log in and go to your **Dashboard**.
2. Find the link you want to edit.
3. Click the link row or the **Edit** button.
4. Make your changes in the edit panel.
5. Click **Save**.

## What you can change

| Field | Notes |
|---|---|
| **Slug** | The short link path (e.g. `gftv.asia/your-slug`). Changing this immediately breaks the old URL. |
| **Destination URL** | Where visitors are redirected. Must be a valid URL and cannot point to `gftv.asia`. |
| **Active status** | Toggle the link on or off. See [Link Status](link-status.md). |
| **Tags** | Add or remove tags (up to 5). See [Link Tags](link-tags.md). |
| **Owner** | Transfer the link to another user. See below. |

## Transferring ownership

You can hand a link over to another Editor on the platform:

1. Open the edit panel for the link.
2. Find the **Owner** field and enter the username of the new owner.
3. Click **Save** (or the transfer button).

{% hint style="warning" %}
Ownership transfers are immediate. Once transferred, the link will no longer appear in your Dashboard and you will not be able to edit it unless you request ownership back.
{% endhint %}

Alternatively, another user can initiate a request to take ownership of your link — see [Ownership Requests](ownership-requests.md).

## Editing someone else's link

If you need to edit a link you don't own, you have two options:

1. **Request ownership** — see [Ownership Requests](ownership-requests.md).
2. **Ask an Admin** — Admins can edit any link directly.

## Frequently asked questions

**Will changing the slug break existing QR codes?**
Yes. Any QR codes or shared links using the old slug will stop working the moment the slug is changed. Make sure to update any distributed materials if you change a slug.

**Can I revert changes?**
There is no automatic version history for link edits. If you accidentally change a slug or destination, simply edit the link again to restore the correct values.

**Can I edit a link while it is inactive?**
Yes. You can edit an inactive link and re-activate it at any time.
