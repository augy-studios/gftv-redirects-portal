# Link Status

Every short link on gftv.asia is either **Active** or **Inactive**. You can toggle the status of any link you own at any time.

## Active links

When a link is **Active**, visitors who go to `gftv.asia/your-slug` are immediately redirected to the destination URL you set.

Active links are visible in the [Directory](../directory/browsing-the-directory.md) and show a green **Active** badge.

## Inactive links

When a link is **Inactive**, visitors who go to `gftv.asia/your-slug` are redirected to the **GFTV blog** instead of the original destination. The short link effectively becomes unreachable for the duration it is inactive.

Inactive links still appear in the Directory, but show a red **Inactive** badge so other officers are aware.

{% hint style="info" %}
Deactivating a link is a non-destructive action. The slug, destination URL, tags, and view history are all preserved. You can re-activate the link at any time.
{% endhint %}

## Toggling link status

**From your Dashboard:**

1. Find the link in your Dashboard list.
2. Click the **Active / Inactive** toggle next to the link.
3. The status changes immediately, so no confirmation is required.

**From the edit panel:**

1. Open the edit panel for the link.
2. Toggle the **Active** switch.
3. Click **Save**.

## When to deactivate a link

Consider deactivating a link when:

* The destination URL is temporarily unavailable or under maintenance.
* The link was created for a time-limited event that has ended.
* You suspect the link's destination may have been compromised, and you need time to investigate.
* You want to replace the destination but need a brief pause to update materials.

{% hint style="warning" %}
Do not delete a link if you might need it again. Deactivating is always reversible; deleting is permanent.
{% endhint %}

## Deleting a link

To permanently remove a link:

1. Open the edit panel for the link from your Dashboard.
2. Click **Delete**.
3. Confirm the deletion in the dialog.

Deleted links cannot be recovered. The slug is freed up immediately and can be claimed by anyone.
