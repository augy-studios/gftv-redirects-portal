# QR Codes

gftv.asia can generate a QR code for any short link. QR codes are useful for physical materials like posters, flyers, and event banners where people cannot click a link directly.

## Generating a QR code

1. Log in and go to your **Dashboard** (or find the link in the [Directory](../directory/browsing-the-directory.md)).
2. Find the link you want a QR code for.
3. Click the **QR Code** button or icon on the link card.
4. A QR code image is generated instantly.

## The QR code image

The generated image is a **composite PNG** that includes:

* The **QR code** itself.
* The **short link URL** (`gftv.asia/your-slug`) printed as text below the QR code.

This makes the image suitable for print use — even if the QR code cannot be scanned, the text URL is still readable.

## Saving and sharing

From the QR code panel you can:

| Action                | How                                                                                                     |
| --------------------- | ------------------------------------------------------------------------------------------------------- |
| **Download**          | Click **Download** to save the composite PNG to your device.                                            |
| **Copy to clipboard** | Click **Copy** to copy the image to your clipboard for pasting directly into documents or design tools. |
| **Share**             | On supported mobile devices, click **Share** to use the native OS share sheet.                          |

## QR codes and security

All QR codes generated by gftv.asia point to a `gftv.asia/...` URL. Even if someone photographs your QR code and reprints it, scanning the copy will still take the visitor through the `gftv.asia` short link, which they can verify in their browser's address bar before proceeding.

{% hint style="success" %}
Because the short link URL itself is trustworthy (only GFTV officers can create `gftv.asia` links), community members can be confident that a QR code bearing the `gftv.asia` domain is legitimate, regardless of where they see it printed.
{% endhint %}

## Frequently asked questions

**Does the QR code update if I change the destination URL?** Yes. The QR code encodes the short link URL (e.g. `gftv.asia/discord`), not the destination. If you update the destination for the short link, the same QR code will take visitors to the new destination automatically.

**What if I change the slug?** The QR code encodes the slug. If you change the slug, any previously distributed QR codes will stop working. Always regenerate and redistribute QR codes after changing a slug.

**Can I customise the QR code design?** Currently the QR code image uses the platform's standard style. For custom-branded QR codes, you can download the PNG and edit it in your preferred design tool, but just make sure the QR code itself is not altered.
